## 日本語プロンプトアプリの設定

メモリを日本語で記録させるには、プロンプトアプリを作成して日本語指定する。

### Omi アプリでの設定手順

1. Omi アプリ → **Apps** → **+** → **Prompt-based**
2. **Memory Prompt** に以下を設定:

```
あなたは会話から重要情報を日本語で抽出するアシスタントです。

以下の情報を必ず日本語で抽出してください:
- 話者の名前と役割
- 重要なトピック
- 感情の状態
- 次回会ったときに話すべき内容
- キーワード

出力は常に日本語で行ってください。
```

3. **Chat Prompt** に以下を設定:

```
あなたは日本語で会話する個人アシスタントです。
ユーザーの記憶と会話履歴を参照して、日本語で回答してください。
```

## 音声認識の日本語精度向上

### 推奨環境
- 静かな室内環境
- マイクから 30cm 以内で話す
- はっきりとした発音
- Consumer 版 (CV1) のデュアルマイクが有利

### 認識率が低い場合の対処

```python
# Webhook で受信したセグメントを後処理
import re

def clean_japanese_transcript(text: str) -> str:
    """日本語文字起こしの後処理"""
    # よくある誤認識の修正
    corrections = {
        "さぼろう": "サボロー",
        "SABOROU": "サボロー",
        "AWS サミット": "AWSサミット",
    }
    for wrong, correct in corrections.items():
        text = text.replace(wrong, correct)
    
    # 句読点の正規化
    text = re.sub(r'\s+', '', text)  # 余分なスペース除去
    return text
```

## バッテリー管理 (日本語ユーザーの実体験)

- **24時間連続使用**: 100% → 30% 程度
- **推奨運用**: 寝る前に充電 → 起きたら装着
- **月 1,200分制限** (基本プラン): 1日40分相当 → 日常使用で到達可能
- **録音セッションの管理**: 重要な会議だけ録音する設定も可

```python
# 月の使用量を確認する CLI コマンド

import subprocess
```

## よくある日本語環境の問題と解決策

| 問題 | 解決策 |
|------|--------|
| サマリーが英語になる | プロンプトアプリで日本語指定 |
| 名前が正しく認識されない | 「田中さん」→「Tanaka-san」で登録 |
| 敬語の誤認識 | 後処理スクリプトで補正 |
| フォントが中華フォント | アプリ側の問題、将来修正予定 |
| 「の」「は」などの助詞が削除される | Bedrock で後処理して補完 |
