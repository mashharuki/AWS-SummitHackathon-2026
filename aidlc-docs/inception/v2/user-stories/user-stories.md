## Epic E-V2-01: Chrome 拡張常駐体験

### US-V2-01: Side Panel UI の起動

```
田中 ユカ として、
Chrome を開いたときに SABOROU の Side Panel が自動で表示されることで、
わざわざアプリを開かずにサボローに話しかけられるようにしたい。
```

**受け入れ基準**:
- Chrome 拡張インストール後、Side Panel が右側に自動表示される
- ページを移動しても Side Panel が消えない
- Side Panel 内にサボローのアバター（アイコン）と会話 UI が表示される

### US-V2-02: Slack 通知の自動検知

```
田中 ユカ として、
Chrome で Slack を開いたときに自分宛てのメッセージをサボローが自動で検知することで、
Slack の通知をいちいち確認しなくてよくなりたい。
```

**受け入れ基準**:
- `https://app.slack.com` で自分宛て DM を content script が検知する
- 検知後 1 秒以内に Side Panel に通知が表示される
- 音声で「〇〇さんからメッセージが来ています」と通知される
- DM とチャンネルメンションを区別して通知できる

## Epic E-V2-02: 音声対話エージェント

### US-V2-03: 音声でサボり判定を聞く

```
田中 ユカ として、
「これどうする？」と声で聞くだけでサボローがタスクの判定を音声で答えてくれることで、
キーボードを触らずに今日の意思決定ができるようにしたい。
```

**受け入れ基準**:
- マイクボタンを押すと録音開始（STT: ElevenLabs Conversational AI SDK）
- 発話を認識してサボり判定（can_saboru / borderline / must_do）を返す
- 判定結果と返信案を音声で読み上げる（TTS: ElevenLabs）
- 判定と合わせて返信文の候補が Side Panel のテキストにも表示される

### US-V2-04: 承認後の自動送信

```
田中 ユカ として、
「いいよ」と発声するだけで返信が Slack に送られることで、
文章を考えることも送信ボタンを押すことも不要になりたい。
```

**受け入れ基準**:
- 音声で「いいよ」「OK」「送って」「いけ」を認識すると送信確認状態に入る
- 3 秒のカウントダウン後に自動送信（否定語または沈黙でキャンセル）
- 送信後「送りました」と音声で確認通知される
- 音声認識が失敗した場合は「いいよ」ボタン（UI）でフォールバック可能

### US-V2-05: 音声でキャンセル

```
田中 ユカ として、
「やっぱりいい」と言うだけで送信をキャンセルできることで、
音声 UI での誤送信リスクなく使えるようにしたい。
```

**受け入れ基準**:
- 「やっぱりいい」「やめて」「キャンセル」を認識するとキャンセル状態に入る
- 沈黙 3 秒でもキャンセルされる
- キャンセル後「キャンセルしました」と音声で通知される

## Epic E-V2-03: Slack 自動返信・断り文

### US-V2-06: 返信文の自動生成

```
田中 ユカ として、
Slack メッセージへの返信文をサボローが自動で考えてくれることで、
「何と返せばいいか」を考える精神的コストがなくなりたい。
```

**受け入れ基準**:
- メッセージ検知後、Bedrock Claude Sonnet 4.6 が返信文案を生成する
- 生成された返信文が Side Panel に表示され、同時に音声で読み上げられる
- 「〜の件は今日中は難しいので、明日午前中に確認します」のような自然な日本語

### US-V2-07: 断り文の自動生成

```
田中 ユカ として、
断りたいタスクに対してサボローが辞退理由を考えてくれることで、
「断り方が分からない」という精神的ブロックがなくなりたい。
```

**受け入れ基準**:
- サボり判定が `can_saboru` または `borderline` で今週リソースが逼迫している場合、断り文を生成する
- 「今週リソースが厳しい状況でして、来週の対応でよろしいでしょうか？」のような自然な断り文
- 承認後に Slack の入力欄に自動入力 → 送信

### US-V2-08: Slack 入力欄への自動入力と送信

```
田中 ユカ として、
「いいよ」と言った後に Slack の入力欄に自動で文字が入力されて送信まで完了することで、
Slack アプリを一切操作しなくてよくなりたい。
```

**受け入れ基準**:
- content script が Slack の ContentEditable 入力欄に文字を挿入できる
- `InputEvent` / `execCommand` による React 合成イベントのシミュレーション
- 送信ボタンをクリックイベントで発火し、送信完了を確認
- 送信成功後に Side Panel に「送信完了」を表示

## Epic E-V2-04: 進捗報告の外部化

### US-V2-09: 進捗報告の自動生成と音声通知

```
田中 ユカ として、
毎日 17:00 にサボローが自動で進捗報告文を作って「送りますか？」と聞いてくれることで、
「報告しなきゃ」というプレッシャーから解放されたい。
```

**受け入れ基準**:
- EventBridge Scheduler が毎日 17:00 JST に Lambda を起動
- タスクの状態を確認し、進捗報告文を自動生成（未完了でも「確認・調整中」と演出）
- Side Panel に「報告しますか？」の通知と報告文案が表示される
- 「うん」発声または承認ボタンで Slack 送信
- 送信後「報告しました」と音声通知

## Epic E-V2-05: MCP 連携基盤

### US-V2-10: ElevenLabs SDK が MCP 経由でサボロー機能を呼び出す

```
田中 ユカ として（技術的透過性の観点）、
ElevenLabs の会話フローから SABOROU のサボり判定や Slack 返信機能が
シームレスに呼び出されることで、音声対話と実業務処理が一本化された体験を得たい。
```

**受け入れ基準**:
- ElevenLabs Conversational AI SDK が AgentCore Gateway の MCP エンドポイントに接続できる
- `saborou_judge_sabori` / `saborou_send_slack_reply` / `saborou_get_tasks` の 3 ツールが MCP 経由で呼び出せる
- Cognito JWT による認証が正常に機能する
- Chrome 拡張内に API キーが保存されない
