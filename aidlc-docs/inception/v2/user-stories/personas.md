### v2 での 1 日の体験

| 時刻 | v2 での体験（Chrome 拡張常駐） |
|------|-------------------------------|
| 07:30 | Slack を開く。側面の Side Panel のサボローが「新着メッセージ 3 件、確認しますか？」と音声で語りかける |
| 09:00 | 作業中のページの横のサボローに「これ今日やる必要ある？」と声で聞く |
| 10:30 | サボローが「まだリマインド来てないし、別件で忙しそうだから寝かせていいよ。返信はこれでどう？」→ 「いいよ」→ Slack 送信完了 |
| 14:00 | 「あの件断りたいんだけど」→ 「今週リソースが厳しい状況でして、来週の対応でよろしいでしょうか？」→ 「それで行こう」→ 送信 |
| 17:00 | サボローが「今日の作業、一応進んでますよ報告しておきました」と音声で告知 |
| 22:00 | 通知はサボローが仕分けてくれているから Slack を開く気にならない |

### 心理プロファイル

- **達成欲求**: 高い（完璧主義だが時間が足りない）
- **意思決定疲れ**: Slack 返信の「何と言うか」を考えることに精神的コストを感じている
- **AI への信頼度**: 中〜高（便利だと分かれば積極的に委ねる）
- **音声 UI への親和性**: 高（スマートスピーカーを日常使用）

### v1 → v2 の変化

- v1: 「画面を開いてクリックして決める」体験
- v2: 「声で委ねる」体験。意思決定コストがさらに下がり、気づいたら全部任せている

> 「声で『いいよ』と言うだけで全部終わる。もう自分で考える必要がない。——それが怖くて、でもやめられない。」

## v2 特有のペルソナ行動パターン

### 「音声で委ねる」ループ

```
[メッセージ検知] → [サボローが音声で読み上げ] → [「いいよ」発声] → [自動送信]
                                    ↓
                    [次第に「自分で返信を考える」能力が退化]
                                    ↓
                    [サボローなしでは Slack 返信できなくなる]
```

### 「進捗報告の外部化」ループ

```
[17:00 自動報告] → [ユーザーが「うん」] → [未完了でも「報告している感」]
                           ↓
                 [締切への危機感が薄れる]
                           ↓
                 [次回も同じパターンを繰り返す]
```
