## 1. 現状診断

### 1-1. 既存ゲーミフィケーション要素の棚卸し

| 要素 | 実装場所 | Octalysisドライバー | 強度 |
|------|---------|-------------------|------|
| AI依存度スコア | `DependencyScoreDisplay.tsx` / `useDependencyScore.ts` | 8（損失回避）、4（所有感） | ★★★ |
| 心理学シグナルカード | `PsychSignalsCard.tsx` | 1（意味・使命感）、7（予測不能） | ★★★ |
| サボロー人格（キャラクター） | `PersonaRenderer.ts` | 5（ソーシャル的信頼感） | ★★☆ |

| 本音フィードバック | `QuickReplyButtons.tsx` | 3（創造・自己表現） | ★★☆ |

### 1-2. 現状コアループの分析

```
現在のコアループ（弱い）：

Slackにタスクが来る → AIが提案を生成（20秒）→ 読む → 本音ボタンを押す → 終了
         ↑                                                       |
         └───────────────────────────────────────────────────────┘
         （次にアプリを開く理由が生まれない）
```

**問題の核心**: 「もう1回！」が発生しない設計。タスク処理ごとにセッションが完結してしまい、継続動機がない。

### 1-3. 面白さスコアカード（現状評価）

```
面白さスコアカード（1〜5点）:
[3] コアループの気持ちよさ    ← AIの提案は面白いが「繰り返す欲求」が弱い
[1] 難度曲線の適切さ         ← 難易度概念がない（全タスク均一体験）
[3] 報酬の満足感             ← AI依存度スコアはあるが演出が弱い
[1] 社会的要素の充実度       ← ほぼゼロ（ランキング・シェアなし）
[4] ビジュアル・サウンドの訴求力 ← Three.js 3Dが高品質
[4] 「面白そう」に見えるか   ← コンセプト（人をダメにする）が強い
[3] 継続したいか（リテンション） ← 毎日戻る強い理由がない

合計: 19/35点 → ⚠️ 根本的なコアループを見直すフェーズ
```

### 1-4. Octalysis 弱点マップ

```
現在 STRONG:
  ✅ 1（意味・使命感）: 科学的根拠5理論が説得力を生む
  ✅ 7（予測不能）: AI提案の内容が毎回異なる

現在 WEAK（補強が必要）:
  ❌ 2（達成・進歩）: レベルアップ・成長の可視化がない
  ❌ 5（ソーシャル）: ランキング・競争・共有がない
  ❌ 8（損失回避）: 「毎日戻らないと損」の仕組みがない
  △  4（所有感）: AI依存度スコアはあるが"コレクション感"がない
  △  6（希少性）: 限定報酬・期間限定要素がない
```

### 1-5. プレイヤータイプ分析（ターゲット別）

| プレイヤータイプ | 現在の対応度 | 補強策 |
|---------------|------------|--------|
| **Explorer（探索）**: 心理学理論の深みを探る | ★★★ 充実 | — |
| **Achiever（達成）**: AI依存度MAXを目指す | ★☆☆ 弱い | 称号・レベル解除システム |
| **Socializer（社交）**: 友達に見せたい | ★☆☆ ほぼなし | シェアカード・SNS連携 |
| **Killer（競争）**: 審査員に勝ちたい | ★★☆ 中程度 | ランキング・比較UI |

## 2. ゲーミフィケーション強化戦略

### 2-1. 戦略の方針

> **「人をダメにする」をゲーミフィケーションで徹底的に体現する。**
> 
> AI依存が増えていく過程そのものをゲームの「成長物語」として設計し直す。
> ユーザーが「ダメになっていくこと」を楽しみ、誇り、シェアするループを作る。

### 2-2. 強化後のコアループ（設計案）

```
強化後のコアループ（ターゲット）：

[サボり判定を受ける]
        ↓
[即時フィードバック: 「サボりスコアA！」エフェクト + 効果音]
        ↓
[AI依存度スコアが増加 → レベルアップアニメーション]
        ↓
[称号解除演出: 「AI見習い」→「サボりの達人」→「AI奴隷」]
        ↓
[本音を入力 → 「取扱説明書 完成度 +3%」進捗バー更新]
        ↓
[「今日のサボり記録を共有」ワンタップシェアボタン]
        ↓
[「明日も連続サボり記録を続ける」動機付け]
        ↓（翌日）
[ログイン → 「連続サボり 7日！🔥」ストリーク表示]
```

### 2-3. 強化後の面白さスコアカード（目標値）

```
目標スコアカード（1〜5点）:
[4] コアループの気持ちよさ    ← サボりスコア即時フィードバック追加
[3] 難度曲線の適切さ         ← タスク難易度A〜E評価で差別化
[4] 報酬の満足感             ← 称号解除・レベルアップ演出強化
[3] 社会的要素の充実度       ← シェアカード・ランキング追加
[4] ビジュアル・サウンドの訴求力 ← 現状維持 + 演出強化
[5] 「面白そう」に見えるか   ← デモシナリオ最適化で最大化
[4] 継続したいか（リテンション） ← ストリーク・取扱説明書完成度

目標合計: 27/35点 → ポリッシュフェーズへ
```

### 3-1. Tier 1：デモ必須施策（2026-05-24〜25、残り2日）

#### 🎯 施策1: AI依存度スコアの「育成ゲーム化」（最優先）

**実装場所**: `DependencyScoreDisplay.tsx`, `TaskDetailPage.tsx`

**設計内容**:

### 施策A：サボり成長ジャーニー（難度曲線 3→5）

SABOROUの「難度曲線」を独自に再定義する。  
ゲームの難度ではなく **「AIがどれだけあなたを理解しているか」の成熟曲線** として設計する。

```
サボり成長の4フェーズ：

Phase 1「サボり見習い」（依存度 0〜25%）
  → AIの提案に驚く・信じていいか迷う段階
  → 心理学シグナルを毎回丁寧に解説（Tutorial Soft 相当）
  → UI: 「初めてのサボり」チュートリアルガイドが表示される
  → キャラクター: 「一緒に考えましょう」という寄り添い口調

Phase 2「サボりの常習者」（依存度 26〜50%）
  → AIの提案パターンを学習・予測できるようになる
  → 提案前に「これA評価だな」と読めるようになる（スキル向上感）
  → UI: 心理学シグナルの解説が簡略化（上級者モードへ自動移行）
  → 新機能解放: 「サボり確率プレビュー」（タスク名を見ただけで予測表示）

Phase 3「サボりの達人」（依存度 51〜75%）
  → AIがユーザーのパターンを学習し、より精度の高い提案へ
  → 「いつもと違うサボり理由」が登場（探索・発見の楽しさ）
  → UI: 「あなた専用の傾向レポート」が解放
  → 転調: 「あなたは○○のときにサボりやすい」という逆AI分析が開始

Phase 4「AI奴隷（存在する怠惰）」（依存度 76〜100%）
  → AIが先回りして「今日サボれそうなタスク」を自動フラグ
  → ユーザーが判断する前にAIが答えを出す（完全依存完成）
  → UI: 全画面金色テーマに変化
  → 最終解放: 「あなたの取扱説明書 PDF出力」ボタン出現
```
